# NeonAdmin 组件使用说明

## 项目简介

NeonAdmin 是一个基于 Vue 3 + Vite + Element Plus 构建的后台管理系统模板。提供了丰富的业务组件和工具函数，帮助开发者快速构建企业级后台应用。

### 技术栈

- **Vue 3** - 渐进式 JavaScript 框架
- **Vite** - 下一代前端构建工具
- **Element Plus** - Vue 3 组件库
- **Pinia** - Vue 状态管理
- **Vue Router** - 路由管理
- **ECharts** - 数据可视化
- **UnoCSS** - 原子化 CSS 引擎

## 核心组件

### 1. NeonForm 表单组件

基于 Element Plus 构建的动态表单组件，通过 JSON 配置驱动表单渲染。

#### 特性

- 动态表单渲染 - 通过 JSON 配置自动生成表单
- 折叠/展开功能 - 支持长表单的折叠展示
- 丰富控件支持 - 内置多种表单控件类型
- 表单验证集成 - 无缝集成 Element Plus 验证
- 自定义按钮配置 - 灵活配置操作按钮
- 帮助提示系统 - 支持表单项帮助信息
- 插槽扩展 - 支持自定义表单项和按钮区域

#### Props 配置

| 属性               | 类型    | 默认值           | 描述                  |
| ------------------ | ------- | ---------------- | --------------------- |
| modelValue         | Object  | {}               | 表单数据，配合 `v-model` 使用 |
| schema             | Array   | []               | 表单项配置数组        |
| commonConfig       | Object  | {}               | 公共配置对象          |
| collapsed          | Boolean | true             | 默认是否展开          |
| showCollapseButton | Boolean | false            | 是否显示折叠/展开按钮 |
| collapseButtonText | Array   | ['展开', '收起'] | 折叠/展开按钮的文本   |
| collapseCount      | Number  | 2                | 默认显示多少项        |

#### commonConfig 配置

| 属性                | 类型                          | 默认值         | 描述                                             |
| ------------------- | ----------------------------- | -------------- | ------------------------------------------------ |
| labelPosition       | String                        | 'right'        | 表单项标签的位置 'left', 'right', 'top'          |
| buttonAlign         | String                        | 'right'        | 按钮对齐方式，可选 'start' / 'center' / 'right'  |
| row                 | Object                        | { gutter: 18 } | 透传给 el-row 的配置（gutter / justify / align） |
| col                 | Object                        | { span: 24 }   | 全局默认列配置，透传给每个字段的 el-col          |
| buttonCol           | `false` \| Object \| `'auto'` | false          | 按钮列配置，见下方「栅格布局」                   |
| submitButtonOptions | Object                        | -              | 提交按钮的配置                                   |
| resetButtonOptions  | Object                        | -              | 重置按钮的配置                                   |
| cancelButtonOptions | Object                        | -              | 取消按钮的配置                                   |

#### 栅格布局

表单布局由 Element Plus 的 `el-row` / `el-col` 栅格系统驱动，通过 `commonConfig` 控制每行显示几列，**无需再书写 `grid-cols-*`**（`.neon-form` 已不再是 `display: grid`，旧写法已失效）。

| 配置        | 类型                          | 默认值         | 说明                                        |
| ----------- | ----------------------------- | -------------- | ------------------------------------------- |
| row         | Object                        | { gutter: 18 } | 透传给 el-row（gutter / justify / align）   |
| col         | Object                        | { span: 24 }   | 全局默认列配置，透传给每个字段的 el-col     |
| buttonCol   | `false` \| Object \| `'auto'` | `false`        | 按钮列配置，见下方                          |
| buttonAlign | String                        | 'right'        | 按钮对齐，可选 'start' / 'center' / 'right' |

- `col`：全局默认列配置，默认 `{ span: 24 }`（每行一列）；设为 `{ span: 12 }` 即每行两列，可配合断点做响应式。
- `item.col`：单个字段用 `col` 覆盖全局配置，合并规则为 `{ ...commonConfig.col, ...item.col }`。
- `buttonCol`：`false`（默认，按钮独占一行）/ 对象（走 `el-col` 原生 `span`、`offset` 等）/ `'auto'`（按钮并入最后一行并占满剩余空间）。
- `buttonAlign`：`'start'` / `'center'` / `'right'`（默认）。
- 列数受 24 等分栅格限制，只能取 24 的约数：1、2、3、4、6、8、12、24，无法实现 5、7、9 列。
- 断点使用 Element Plus 的（`sm` 768 / `md` 992 / `lg` 1200 / `xl` 1920），与 UnoCSS 断点（`sm` 640 / `md` 768 / `lg` 1024 / `xl` 1280 / `2xl` 1536）不同，`:md="12"` 指的是 992px。

```js
const formConfig = ref({
    // 全局默认每行一列；md 起两列，lg 起三列
    col: { span: 24, md: 12, lg: 8 },
    // 单个字段可单独覆盖，例如 { label: '备注', key: 'remark', col: { span: 24 } }
    // 按钮列：false（独占一行）| { span: 8, offset: 16 } | 'auto'（占满剩余空间）
    buttonCol: 'auto',
    // 按钮对齐：'start' / 'center' / 'right'（默认）
    buttonAlign: 'right',
})
```

#### Schema 配置

| 属性   | 类型    | 描述                                                                                                                                                                                                                 |
| ------ | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| label  | String  | 表单项的标签                                                                                                                                                                                                         |
| key    | String  | 表单项的唯一标识（字段名）                                                                                                                                                                                           |
| type   | String  | 表单项的类型, 默认 'input', 可选值: 'input', 'number', 'select', 'selectV2', 'radio', 'checkbox', 'date', 'time', 'timeSelect', 'autocomplete', 'cascader', 'inputTag', mention , 'rate', 'slider', 'switch', 'tree' |
| style  | Object  | 表单项的样式                                                                                                                                                                                                         |
| col    | Object  | 该字段的列配置，覆盖 commonConfig.col（详见「栅格布局」）                                                                                                                                                            |
| rules  | Array   | 表单项的验证规则                                                                                                                                                                                                     |
| help   | String  | 表单项的帮助提示信息                                                                                                                                                                                                 |
| hidden | Boolean | 是否隐藏该表单项                                                                                                                                                                                                     |
| props  | Object  | 传递给表单项组件的额外属性(见 Element Plus)                                                                                                                                                                          |
| slots  | Object  | 表单项的插槽配置(见 Element Plus)                                                                                                                                                                                    |

#### 事件

| 事件名 | 参数     | 描述               |
| ------ | -------- | ------------------ |
| submit | formData | 表单验证通过后触发 |
| reset  | formData | 表单重置时触发     |
| cancel | -        | 取消操作时触发     |

#### 方法

| 方法名        | 说明                                         | 返回值  |
| ------------- | -------------------------------------------- | ------- |
| validate      | 校验整个表单，可传入 Element Plus 的回调     | Promise |
| validateField | 校验指定的若干字段，参数为字段名或字段名数组 | Promise |
| resetFields   | 重置表单，将值恢复为初始值并移除校验结果     | -       |
| clearValidate | 移除表单的校验结果                           | -       |
| setState      | 动态设置 `commonConfig` 配置                 | -       |
| getValues     | 获取当前表单数据                             | Object  |

#### 基础使用示例

```vue
<template>
    <NeonForm
        v-model="formValues"
        :schema="formSchema"
        :commonConfig="formConfig"
        @submit="handleSubmit"
        @reset="handleReset"
        @cancel="handleCancel" />
</template>

<script setup>
import { ref } from 'vue'

const formValues = ref({
    name: '',
    age: null,
})

const formSchema = ref([
    {
        label: '姓名',
        key: 'name',
        type: 'input',
        rules: [{ required: true, message: '请输入姓名', trigger: 'blur' }],
    },
    {
        label: '年龄',
        key: 'age',
        type: 'number',
        rules: [{ required: true, message: '请输入年龄', trigger: 'blur' }],
    },
])

const formConfig = ref({
    buttonAlign: 'right',
    submitButtonOptions: {
        text: '保存',
    },
    resetButtonOptions: {
        text: '清空',
    },
})

const handleSubmit = (data) => {
    console.log('提交数据:', data)
}

const handleReset = (data) => {
    console.log('重置数据:', data)
}

const handleCancel = () => {
    console.log('取消表单')
}
</script>
```

#### 使用 useNeonForm Hook

```vue
<template>
    <BaseForm />
</template>

<script setup>
import { useNeonForm } from '@/hooks'

const [BaseForm, formApi] = useNeonForm({
    modelValue: formValues,
    schema: formSchema,
    commonConfig: formConfig,
    onSubmit: async (data) => {
        await formApi.validate()
    },
    onReset: (data) => {},
    onCancel: () => {},
})

// 调用方法
formApi.validate()
formApi.resetFields()
formApi.getValues()
</script>
```

### 2. NeonTable 表格组件

基于 Element Plus 构建的增强表格组件，支持分页、自定义列渲染等功能。

#### Props 配置

| 属性        | 类型    | 默认值      | 描述         |
| ----------- | ------- | ----------- | ------------ |
| columns     | Array   | []          | 表格列配置   |
| dataSource  | Array   | []          | 表格数据源   |
| options     | Object  | {}          | 表格配置选项 |
| loading     | Boolean | false       | 是否加载中   |
| loadingText | String  | '加载中...' | 加载提示文本 |

#### 列配置 (columns)

| 属性      | 类型     | 描述                                   |
| --------- | -------- | -------------------------------------- |
| prop      | String   | 列字段名                               |
| label     | String   | 列标题                                 |
| width     | String   | 列宽度                                 |
| align     | String   | 对齐方式                               |
| type      | String   | 列类型: 'index', 'selection', 'expand' |
| slot      | String   | 插槽名称                               |
| formatter | Function | 格式化函数                             |
| render    | Function | 自定义渲染函数                         |
| children  | Array    | 多级表头配置                           |

#### 分页配置 (options.pagination)

| 属性           | 类型    | 默认值                                    | 描述         |
| -------------- | ------- | ----------------------------------------- | ------------ |
| showPagination | Boolean | true                                      | 是否显示分页 |
| total          | Number  | 0                                         | 数据总数     |
| currentPage    | Number  | 1                                         | 当前页码     |
| pageSize       | Number  | 30                                        | 每页条数     |
| pageSizes      | Array   | [10, 20, 30, 40, 50, 100]                 | 每页条数选项 |
| background     | Boolean | true                                      | 是否显示背景 |
| layout         | String  | 'total, sizes, prev, pager, next, jumper' | 分页布局     |

#### 事件

| 事件名           | 参数                    | 描述             |
| ---------------- | ----------------------- | ---------------- |
| sizeChange       | pageSize                | 每页条数改变触发 |
| currentChange    | currentPage             | 当前页改变触发   |
| paginationChange | (currentPage, pageSize) | 分页改变触发     |

#### 使用示例

```vue
<template>
    <NeonTable
        :columns="columns"
        :dataSource="tableData"
        :options="tableOptions"
        :loading="loading"
        @paginationChange="handlePaginationChange">
        <template #status="{ row }">
            <el-tag :type="row.status === 1 ? 'success' : 'danger'">
                {{ row.status === 1 ? '启用' : '禁用' }}
            </el-tag>
        </template>
        <template #action="{ row }">
            <el-button
                type="primary"
                link
                @click="handleEdit(row)"
                >编辑</el-button
            >
            <el-button
                type="danger"
                link
                @click="handleDelete(row)"
                >删除</el-button
            >
        </template>
    </NeonTable>
</template>

<script setup>
import { ref } from 'vue'

const loading = ref(false)
const tableData = ref([])

const columns = ref([
    { type: 'selection' },
    { type: 'index', label: '序号', width: '80' },
    { prop: 'name', label: '姓名', width: '120' },
    { prop: 'age', label: '年龄', width: '100' },
    { prop: 'status', label: '状态', slot: 'status' },
    { prop: 'action', label: '操作', slot: 'action', width: '180' },
])

const tableOptions = ref({
    pagination: {
        total: 100,
        currentPage: 1,
        pageSize: 10,
    },
})

const handlePaginationChange = (page, size) => {
    console.log('分页改变:', page, size)
}
</script>
```

## 工具函数

### renderDialog 弹窗工具

动态渲染 Element Plus Dialog 对话框的函数，无需在模板中预先定义。

#### 特性

- 动态对话框创建 - 无需在模板中预先定义
- 内容组件封装 - 支持传入任意 Vue 组件作为内容
- 属性动态更新 - 可在运行时修改对话框属性
- 异步操作支持 - 内置加载状态处理
- 抽屉/对话框切换 - 通过 useDrawer 参数切换展示模式
- 实例控制 - 支持获取组件实例和手动关闭

#### 参数说明

| 参数       | 类型         | 默认值 | 说明                          |
| ---------- | ------------ | ------ | ----------------------------- |
| component  | VueComponent | -      | 对话框中显示的内容组件 (必填) |
| modalProps | Object       | -      | 对话框属性和事件配置          |
| props      | Object       | -      | 传递给内容组件的属性          |

#### modalProps 配置

| 参数              | 类型            | 默认值  | 说明                                      |
| ----------------- | --------------- | ------- | ----------------------------------------- |
| title             | String          | '提示'  | 对话框标题                                |
| width             | String / Number | '580px' | 对话框宽度                                |
| alignCenter       | Boolean         | false   | 是否居中显示                              |
| autoHeight        | Boolean         | false   | 是否自动高度                              |
| showConfirmButton | Boolean         | true    | 是否显示确认按钮                          |
| showCancelButton  | Boolean         | true    | 是否显示取消按钮                          |
| confirmButtonText | String          | '确定'  | 确认按钮文本                              |
| cancelButtonText  | String          | '取消'  | 取消按钮文本                              |
| useDrawer         | Boolean         | false   | 是否使用抽屉模式                          |
| drawerProps       | Object          | -       | 抽屉属性和事件配置                        |
| slots             | Object          | -       | 自定义头部和底部按钮操作区 header, footer |
| draggable         | Boolean         | false   | 是否可拖拽                                |

#### 事件

| 事件名    | 参数 | 说明          |
| --------- | ---- | ------------- |
| onConfirm | -    | 确认按钮回调  |
| onCancel  | -    | 取消/关闭回调 |
| onError   | -    | 错误处理回调  |

#### 实例方法

| 方法名   | 参数   | 类型         | 说明                    |
| -------- | ------ | ------------ | ----------------------- |
| setState | Object | Function     | 动态更新对话框props属性 |
| instance | -      | VueComponent | 获取对话框内容组件实例  |
| close    | -      | Function     | 手动关闭对话框          |

## Hooks

### useNeonForm

创建表单组件和 API 的 Hook。

```javascript
import { useNeonForm } from '@/hooks'

const [FormComponent, formApi] = useNeonForm({
    modelValue: formValues,
    schema: formSchema,
    commonConfig: formConfig,
    onSubmit: async (data) => {
        await formApi.validate()
    },
    onReset: (data) => {},
    onCancel: () => {},
})

// formApi 方法
formApi.validate() // 验证表单
formApi.resetFields() // 重置表单
formApi.clearValidate() // 清除验证
formApi.validateField() // 验证指定字段
formApi.setState() // 设置状态
formApi.getValues() // 获取表单值
```

### useRef

创建响应式引用的 Hook。

```javascript
import { useRef } from '@/hooks'

const [formData] = useRef({
    name: '',
    age: null,
})
```

## 项目配置

### 环境变量

项目支持三种环境配置：

- `.env.development` - 开发环境
- `.env.test` - 测试环境
- `.env.production` - 生产环境

### 常用配置项

在 `src/config/index.js` 中可以配置：

| 配置项            | 说明                      |
| ----------------- | ------------------------- |
| META_TITLE        | 网站标题                  |
| LOGIN_PATH        | 登录页面路径              |
| HOME_PATH         | 首页路径                  |
| API_URL           | 接口地址                  |
| REQUEST_TIMEOUT   | 请求超时时间              |
| TOKEN_KEY         | Token 请求头名称          |
| TOKEN_PREFIX      | Token 前缀                |
| ROUTER_MODE       | 路由模式 (history / hash) |
| ELEMENT_PLUS_SIZE | Element Plus 组件尺寸     |
| DEFAULT_LAYOUT    | 默认布局                  |
| ROUTER_ANIMATION  | 路由切换动画              |
| APP_COLOR         | 默认主题颜色              |
